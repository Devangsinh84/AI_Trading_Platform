# AI Trading Platform - MVP Pipeline

## Service A: Python AI Engine Setup
1. Navigate to the `\Python_AI_Engine` directory.
2. Create the virtual environment: `python -m venv`
3. Activate the environment (Windows): `.\venv\Scripts\activat evenv`
4. Install core dependencies: `pip install -r requirements.txt`
